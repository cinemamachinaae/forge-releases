# Cinema Machina Forge releases

Official macOS release downloads for Cinema Machina Forge.

For product details, compatibility, first-launch guidance, and support, visit [cinemamachina.org/forge](https://cinemamachina.org/forge). Downloadable files and checksums are attached to each [GitHub release](https://github.com/cinemamachinaae/forge-releases/releases).

This repository contains release metadata only. It does not contain the Forge application source code.
